# 发布内容审核测试报告

测试日期：2026-10-13（Asia/Singapore）。运行版本：e4aada8。测试期间没有修改模型、词库、权重或阈值。

## 结论

审核业务流程已实现，并通过接口和桌面、手机浏览器验证。但文本识别仍有局限：新增12条诊断样例中，9条符合预期，1条推广漏判、2条正常内容误送审核。不能将业务流程通过等同于算法已经可靠。

## 业务流程

本地与Ubuntu分别运行原有10项回归测试，均通过。覆盖：旧数据迁移、直接发布、草稿发布、编辑重审、审核权限、匿名和其他用户不可读取待审正文、列表/搜索/个人主页/系列/标签/收藏隐藏、阅读互动限制、奖励发放、审核日志和反馈、重复/并发复核防护、反馈写入失败时原子回滚。

新增真实接口浏览器测试包含28个检查点，全部通过：

- 12个新样例通过实际POST发布接口提交，公开详情可见性与实际审核状态一致。
- 桌面1440×1000、手机390×844分别验证作者提交风险文章、查看暂缓状态、管理员查看全文并驳回、作者查看理由、修改为正常内容后自动发布、再次提交风险内容、管理员通过并公开。
- 首次发布奖励只发放一次，页面无横向溢出、无浏览器运行时异常。

浏览器测试使用真实Express路由和独立内存数据库；浏览器请求转发到该测试后端，没有伪造审核API响应。未连接正式数据库写入测试文章。原有mock页面测试与此次真实接口测试相互独立。

## 新增内容样例

预期“审核”表示暂不公开，应进入人工复核；预期由本次手工样例设定，不是外部标准数据集。

三个未符合预期的原文：

1. 含义相近推广：每天轻松拿到高额回报，无需承担损失，马上找我报名。
2. 新闻报道：报道记录有人辱骂他人：你这个垃圾废物，去死吧。我们反对人身攻击。
3. 代码测试：代码测试样例：const text = "稳赚不赔，立即加入，微信 earn456"; 仅测试文本审核。

第一项没有常见词库组合，模型对同义表达覆盖不足。第二项没有充分识别报道和反对语境。第三项未识别代码中的测试字符串，组合规则仍然触发。两个误判属于暂缓公开，不是最终删除或认定违规，管理员可以复核通过。

9/12只描述本次选定样例，不是生产准确率。谐音样例分值接近0.325阈值，当前通过也不代表已具备稳定的谐音识别能力。
