# 明确人身攻击风险规则更新

2026年10月13日，本地实现新增 direct-attack-v1 规则，不改变训练模型权重和特征维度。

识别明确指向人的侮辱组合或恶意死亡表达时，将对应窗口分值提高到至少 0.9，文章按原有最大窗口聚合进入 held。风险证据明确注明规则原因，分值仍不是校准概率。标题、正文和标签使用同一规则。

“你这个垃圾废物，去死吧。”由 0.5117 / pending 变为 0.9 / held。held 表示不公开并等待人工复核，不是自动最终驳回。

规则对明确引入的引号引用以及同句报道、禁止辱骂语境进行局部排除，不降低原模型分值、不对整篇文章放行。引用后继续直接攻击仍会命中。“废物回收项目由他负责”等对象描述不触发指向人的组合规则。

限制：规则仅覆盖有限表达与局部语境。新闻引用仍可能因原模型得到 pending；跨窗口上下文、未覆盖的改写和歧义仍需改进。独立恶意表达采用保守处理，不能宣称完整理解语义。

后端12项测试通过，包括直接攻击、分隔及零宽变体、标题标签、长文局部风险、引用后继续攻击、警示不全局豁免和对象描述。此前桌面材料描述的是旧版本实际验证结果，不应把该51分记录当作当前新评分。

现有文章保存的审核结果不会自动重算，需要作者修改后重新提交。此次未提交Git，也未更新Ubuntu部署。
